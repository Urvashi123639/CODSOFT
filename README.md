# CodeSoft Data Science Internship Projects 🚀

This repository contains all the Machine Learning projects completed during my *CodeSoft Data Science Internship*.

---

## 📌 Projects Overview

### 🔹 Task 1: Titanic Survival Prediction
- Built a classification model to predict passenger survival
- Used Logistic Regression / Random Forest
- Dataset: Titanic (Kaggle)

### 🔹 Task 2: Movie Rating Prediction
- Developed a regression model to predict movie ratings
- Performed data preprocessing and feature analysis

### 🔹 Task 3: Iris Flower Classification
- Implemented a classification model to predict iris species
- Evaluated model using accuracy score

### 🔹 Task 4: Sales Prediction
- Built a regression model to forecast sales
- Performed data analysis and preprocessing

### 🔹 Task 5: Credit Card Fraud Detection
- Developed a classification model to detect fraudulent transactions
- Worked with imbalanced dataset
